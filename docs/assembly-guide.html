1. 本次发现的问题与对应修复

原来出现什么源文件中查到的原因本次改变
多块肌肉红色堆在一起所有肌肉使用同一基础色；归位后也恢复同一红色。每个肌肉目录键使用固定识别色，颜色在托盘、名称点与模型一致。左右同名结构同色，不提示左右答案。红绿只用于短时正误反馈。
小圆肌找不到旧版按3个条目机械分组；小圆肌在第二组，第一组只显示前三块。第一组改为完整肩袖四肌；可从目录直接选中小圆肌，使用“仅看当前”与“推荐视角”。
肩部没有肱二头肌原本只登记在肘章节，肩部目录没有它。肩部新增跨肩上臂组：肱二头肌、喙肱肌、肱三头肌长头。肱二头肌保留已有两头源网格，不拼造肌头。
头颅像缺了半边或部分面骨单侧选择错误地筛掉了配对颅骨的对侧；同时缺少若干面骨、筛骨和牙齿参照。固定头颅参照独立于当前操作侧，双侧加载；从已有源文件补入缺失骨与牙齿，不凭空补形。
标签叠在肌肉中心标签直接放在几何中心，几个结构遮挡时标签挤作一团。标签移到画面两侧并排布引线；兼容光栅化路径还依据可见表面像素放置标签，不给被完全遮住的结构强贴可见标签。

2. 先按这三条路径检查

检查头颅：首页 → 头颅与颞下颌 → 骨骼拼接 → 先看完整头颅参照。正面、背面、侧面、上方均可旋转观察。选择“看全参照”恢复完整取景。

检查小圆肌：首页 → 肩与肩带 → 肌肉安放 → 肩袖四肌 → 先看本章全部肌肉；在观察区选择“肩袖四肌”，点小圆肌 → 仅看当前 → 推荐视角。

检查肱二头肌：同一准备页直接点击肱二头肌名称，进入“跨肩上臂肌”组；也可通过游戏中的“章节肌肉目录”搜索，不必一组组盲找。

原“先看完整参照”只显示当前组。本版肌肉完整参照真正装入本章全部条目；默认完整观察不记录拼接成绩。正式挑战中，待拼骨块会从参考骨架取出放入托盘，这是任务缺口，并非正常颅骨缺损。

3. 配色、隐藏与手形操作

默认“分色辨认”；可切换为“统一组织色”。颜色是结构识别工具，不代表真实组织色、肌纤维类型或肌肉激活。

安放正确：750毫秒绿色反馈、✓和文字，再恢复当前肌肉识别色。安放错误：红色✕，区分侧别、方向、位置和深度错误，再恢复结构色。正确肌肉保持锁定，不会因为观察或隐藏而重复计分。

“仅看当前”隐藏其他肌肉而保留骨性参照；“隐藏当前”暂时去掉遮挡；“显示全部”恢复；点击已隐藏肌肉的名称可重新显示。已归位肌肉可以选中观察，但不能再次拖动。

肩胛下肌位于肩胛前面，不能要求它在后视图越过实体肩胛骨显露；使用前视或“推荐视角”及明确标记的骨骼透视。冈下肌与小圆肌优先背侧观察；肱二头肌优先前侧观察。

鼠标张手表示可拿起，按住变握手，松开检查。拖空白旋转、滚轮/双指缩放；X/Y/Z旋转与位置微调保留。骨骼默认不透明，只有主动开启“骨骼透视参照”时才淡化，避免把深层结构误认作表层。

换组会保存本次各组的安放状态与记录；回到已做过的组，不丢失已归位结构。仅观察不会累计为独立拼接成绩。

5. 头颅参照的准确范围

加载22块脑颅与面颅骨：额骨、左右顶骨、左右颞骨、枕骨、蝶骨、筛骨，以及上颌骨、颧骨、鼻骨、泪骨、腭骨、下鼻甲的左右两侧、犁骨和整块下颌骨。该计数不包括听小骨，舌骨和上颈椎只作周边参照。

牙齿使用原始源文件的28颗恒牙网格（该源未提供第三磨牙），不把牙齿算作骨拼块。下颌拖动和旋转时14颗下牙跟随同一变换，不能悬留在原处。

完整预览显示完整骨架；骨骼练习中仅当前待拼结构从参照取出，其他颅骨固定显示。单侧难度只约束当前任务，不再删掉另一侧固定头颅参照。肌肉任务也保留完整头颅，并以全头范围取景。

模型来自现有BodyParts3D/Human Atlas资源。颅骨缝、微小孔隙、听小骨和关节盘等不代表全部细节都已建模；不作为影像诊断或精细手术模型。
